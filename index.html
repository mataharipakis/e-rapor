Download & Import Template Excel Guru

Pilih kelas dan mata pelajaran untuk mendownload template Excel agar dapat dibagikan dengan mudah ke guru pengampu.

Panduan Penggunaan Template Excel untuk Guru Pengampu:

  • Download template Excel sesuai kelas dan mata pelajaran yang diampu.
  • Buka file menggunakan Microsoft Excel. Kolom NIS dan Nama Siswa sudah tersusun rapi di kolom terpisah.
  • Isikan nilai Ulangan Harian (UH1 s.d. UH5), Tugas (T1 s.d. T5), dan STS pada kolom yang disediakan. Sel yang kosong atau bernilai 0 tidak akan dihitung dalam rata-rata.
  • Simpan file, lalu gunakan tombol Upload / Import File Excel Terisi atau Paste Langsung dari Excel untuk memasukkan nilai secara instan.

Cara Kerja Sinkronisasi Cloud Real-Time

Aplikasi ini terhubung langsung ke database cloud real-time secara otomatis. Berikut cara kerjanya:

  • Simpan Otomatis: Setiap kali Anda mengubah data siswa, nilai, absensi, atau pengaturan sekolah, perubahan tersebut langsung dikirim ke cloud.
  • Lintas Komputer: Saat Anda membuka aplikasi ini di komputer, laptop, atau perangkat lain, data akan otomatis tersinkronisasi tanpa perlu export/import manual.
  • Cadangan Lokal: Sistem juga menyimpan salinan lokal di browser (`localStorage`) sehingga aplikasi tetap dapat berjalan dengan lancar saat koneksi internet offline.
